1. 项目概述

本项目以「本地优先（local-first）」为原则复刻一套科研工作台 Fieldnote Research Studio：全部功能在本机回环地址上运行，不访问外部网络，不连接模型服务、科研数据库、计算集群、实验设备或机器人硬件。运行产生的截图与日志均来自本地实测。

1.1 复刻目标

  • 在本机 127.0.0.1 上提供一套可交互的科研工作台界面，覆盖案例工作流、研究资料、课题空间与对话四条主线。
  • 提供可持久化、可迁移、带最小认证与资源归属隔离的本地后端（SQLite 为事实来源）。
  • 接入 A3S Code Core 会话，验证宿主模型接口可在无凭证、无外网条件下运行，并明确标注模拟边界。

2. 运行环境与安全边界

前后端一律只绑定回环地址，远程访问只走 SSH 隧道；认证与资源访问均设有明确的本地安全策略。

  • 绑定：后端仅监听 127.0.0.1:8081，前端 127.0.0.1:5175，均无 0.0.0.0 暴露。
  • 口令：Argon2id + 每用户随机盐；登录失败信息不区分「邮箱不存在 / 口令错误」，审计记为 bad_password。
  • 会话令牌：32 字节 CSPRNG 随机令牌，服务端仅存 SHA-256 摘要；支持过期与注销（退出即吊销）。
  • 资源归属：资源访问先校验 owner_id == 当前用户，越权一律返回 404（不泄露资源是否存在）。
  • 上传边界：扩展名白名单 pdf / txt / md / csv / json；单文件上限 20 MiB（超限 413）；原始文件名仅作展示，落盘使用服务端随机名并按课题分目录。
  • 无外网调用：示例回复与工具目录均为本地模拟，界面内显式标注。

3. 阶段 A 案例工作流

案例工作流以 «AmeR 蛋白质定向进化» 为演示案例，包含八个可导航的研究阶段，进度与事件可本地保存、推进、刷新恢复与重置。

  • 八阶段：01 定义科学问题 → 02 深入研究 → 03 专家选择路线 → 04 风险评估 → 05 分子动力学模拟 → 06 可信性证据链 → 07 湿实验验证与监测 → 08 结果回流与迭代。
  • 进度操作：可保存进度、推进到下一阶段、一键重置；进度与事件写入本地持久化存储，刷新后可恢复。
  • A3S 会话接入：后端锁定 a3s-code-core = 9.1.1，经宿主模型接口注入本地固定响应 fixture，页面显示运行时事件（如 text_delta、agent_end）与模型调用计数。
边界：该固定响应用来证明 A3S 会话及宿主模型接口可在无凭证条件下工作，不是 AI 推理；案例材料为本地模拟演示数据，不代表经核验的科研结论。

4. 阶段 B 研究资料

「研究资料 / 论文工具」工作区提供三个可导航页签：文献检索、PDF 精读与引文核验；本阶段为前端模拟流程，不是正式文献产品。

  • 文献检索：支持关键词、年份与条目类型过滤，可展开摘要详情，并具备加载 / 空结果 / 输入错误状态；索引内仅有 4 条虚构条目。
  • PDF 精读：本地文件限制为 .pdf、非空、MIME 允许值、文件头 %PDF- 且不超过 20 MiB；仅校验元信息与开头 5 字节，不上传、不解析正文、不持久化文件。
  • 引文核验：判定使用本地字面规则——存在性只匹配本地演示 ID 或完整题名；观点一致性只计算来源文本与观点间的字面词项重合比例，并附判断、依据与不确定性说明。

5. 阶段 C 课题空间与知识库

阶段 C 将后端由单文件演示结构收敛为模块化架构，并补齐本地单机可持久化、可迁移、可备份、带最小认证与资源归属的基础设施。

5.1 模块化后端

后端按职责拆分为 config / error / logging / util / models / db / auth / storage / state / case / agent 等模块，并以 routes/ 目录承载 auth、subjects、case、agent、admin 等路由。

5.2 迁移与数据模型

  • SQLite 为事实来源，启用 PRAGMA foreign_keys = ON 与 WAL 日志模式；时间戳统一为 Unix 秒。
  • 首版迁移 001_initial 建立 users、sessions、subjects、documents、conversations、messages、runs、evidence、audit_events 等表，并以 PRAGMA user_version 记录已应用版本（幂等、事务内执行）。

5.3 安全与边界

  • 认证：除 /api/health、/api/auth/register、/api/auth/login 外，其余接口需 Authorization: Bearer <token>；无令牌 401。
  • 资源隔离：课题 / 文档等资源按所有者隔离，越权访问返回 404。
  • 上传边界：白名单扩展名、文件名校验、随机落盘名、课题分目录，入库记录 SHA-256。
  • 备份：POST /api/admin/backup 使用 VACUUM INTO 生成一致性快照，返回相对路径与 SHA-256。
  • 结构化日志：单行 JSON（ts / level / event / msg / fields）输出到 stderr 并追加到 <data>/logs/app.log；注册、登录成败、课题增删改、文档上传 / 删除、备份均写入审计并落日志。

6. 阶段 E 对话与课题空间闭环

阶段 E 打通「登录 → 建课题 → 上传文件 → 工具关联 → 课题内对话 → 发消息 → 历史与失败态」的核心闭环。

6.1 迁移 002 与接口

  • 新增迁移 002_conversation_loop，只做追加列与新增表：为 conversations 追加 updated_at、mode（quick / deep）、model（选择器占位值），并新增 subject_tools 关联表。
  • 会话 CRUD：GET/POST /api/conversations、GET/DELETE /api/conversations/{id}；对话必须归属课题，删除级联。
  • 发消息落库：POST /api/conversations/{id}/messages 先落库用户消息 → 生成本地模板回复 → 落库助手消息 → 写入 runs（a3s.chat）与 evidence。
  • 工具目录：GET /api/tools 返回只读本地模拟目录，共 12 条（skill 4 类 + scp 8 类），支持 kind/q/field/purpose/sort 过滤。
  • 课题工具关联：GET/POST/DELETE /api/subjects/{id}/tools[/{tool_id}]，关联幂等。

6.2 回复生成（本地模拟）

回复复用 A3S 会话：Agent::new(ACL) → 受限 SessionOptions（默认拒绝工具）→ 注入 fixture LLM 客户端。该客户端为提示词感知的本地模板，输出固定免责声明 + 课题 / 模式 / 知识库附件上下文 + 截断回显用户问题 + 建议路径，并以「本轮未使用网络、未执行任何工具；这是一条模拟回复。」收尾。元数据（运行时、版本、fixture 调用次数、事件名）随助手消息返回，前端展示为「A3S 模拟回复」标签与运行时元数据。
